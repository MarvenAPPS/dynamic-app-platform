# Icons Directory

This directory contains PWA icons for the application.

## Required Icons

- `icon-192.png` - 192x192px icon for PWA
- `icon-512.png` - 512x512px icon for PWA

## How to Add Icons

1. Create or design your icons
2. Export as PNG files
3. Save with the exact filenames listed above
4. Make sure they are square images

You can use tools like:
- Canva
- Figma
- Adobe Illustrator
- Online PWA icon generators
